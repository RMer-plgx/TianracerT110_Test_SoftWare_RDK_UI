# MyGo 检测平台 UI/UX 方案

本方案参考 `mygo-music` 的原生界面结构与视觉语言，服务于[插件化检测平台](mygo-plugin-platform.md)。状态为设计基线：本轮未生成新界面，也未进行新界面的截图或可用性验收。布局尺寸和交互细节通过 P0/P1 原生窗口验证后调整。

## 窗口与信息布局

默认窗口采用参考项目的 `1180 × 780` 逻辑像素。检测版最小窗口暂定 `960 × 640`；侧栏参考宽度 `232`，窄窗口可收为图标栏并提供名称提示。主内容保留顶部标题和底部会话栏的空间，滚动区域不能遮挡操作入口。

```text
┌────────────────┬────────────────────────────────────────────┐
│ 产品 / 设备     │ 页面标题 · 当前产品与设备身份                 │
│ 搜索            ├────────────────────────────────────────────┤
│                │                                            │
│ 产品与连接      │ 连接表单 / 检测列表 / 报告 / 插件管理         │
│ 检测运行        │                                            │
│ 报告与复核      │ 选中检测项后显示测量值、阈值和原始证据        │
│ 插件管理        │                                            │
│ 设置            ├────────────────────────────────────────────┤
│                │ 设备 · 会话状态 · 进度       [查看] [请求停止] │
└────────────────┴────────────────────────────────────────────┘
```

产品切换位于侧栏顶部，显示产品名、插件版本和当前设备。检测期间允许浏览其他页面和历史报告；切换当前执行设备、修改计划或启用另一版本必须先结束本轮。查看其他产品资料不会隐式连接设备，也不会改变底部栏绑定的会话。

首版一次仅运行一轮检测。底部栏由运行时状态驱动，插件无权隐藏、替换或重新命名停止行为。按下停止后先显示“正在请求停止”，收到证据后再显示实际收尾状态。

## 页面与操作流程

### 产品与连接

产品目录以紧凑列表或卡片显示型号、协议、插件版本、支持平台及验收状态。缺驱动、缺能力或开发包的提示就近展示。没有插件时引导从本地安装，安装完成后进入配置，不自动启动检测。

连接页按设备身份、通信参数、报告目录分组。不同插件使用各自 schema：SSH 可展示地址/端口/凭据引用，串口展示受管端口/波特率，SDK 产品展示连接参数。运行时身份核验和错误原因使用统一提示。产品切换时清除不适用参数与旧安全确认，不能把旧设备密码带入新插件。

“下一步”先验证字段并聚焦首个错误，再生成计划预览。预览显示检测项、预计的人工操作、将修改的设备状态和未满足条件；没有实测耗时依据时不显示虚假的剩余时间。

### 检测运行

内容区采用步骤列表与详情组合。每行显示名称、执行状态、判定和最新说明；点击查看测量值、单位、阈值、时间及证据。阶段分组由产品计划提供，不把所有机器人固定为 static/runtime/motion。

进度按已完成步骤展示，未知长度的采样显示活动状态和已耗时；不把等待连接表现为检测已经通过。长日志虚拟化并支持搜索，用户上滚查看后暂停自动跟随，通过明确按钮恢复。

人工操作在步骤旁显示指引和示意图，确认对话框只呈现当前需要回答的内容。安全确认包含设备、动作、范围及现场条件，并绑定本轮计划。确认返回后运行时仍会重新校验，界面不能因点击成功直接标记动作完成。

### 报告与复核

默认同时显示自动结论、证据完整性和待人工处理项。选中项目可并排查看实测值与阈值、原始证据和复核历史。人工接受、撤销及理由在独立区域记录，自动状态保持可见。

打开旧报告时标明格式和证据覆盖范围。导出显示实际目录与完成结果；报告保存失败不能出现成功 toast。未完成会话优先提供状态查看和恢复入口，不提供“一键重新执行上次运动”。

### 插件管理

参考音乐应用的设置列表与更多菜单，显示插件名、已安装版本、来源、支持平台、API 兼容性及当前使用情况。安装前列出批准状态、所需设备能力与辅助程序，无法满足的平台明确标注。

更新完成后显示“新版本用于下一轮”，并展示仍被活动会话固定的旧版本。存在恢复引用时保留旧包。卸载需要先处理相关活动会话；错误显示具体原因，不把“版本已下载”写成“已切换”。

### 异常和恢复

运行时断开、证据写入失败、设备停止不明等状态使用持续可见的提示区，不能仅靠短暂 toast。恢复页展示原设备身份、插件版本、最后确认步骤、停止证据和现场接管说明；操作结果按协议更新。

关闭窗口时若有活动会话，提供“返回检测”和“请求停止并关闭”。选择后先进入取消流程，确认安全收尾后才正常退出；不能确认时保留恢复提示和持久记录。强制结束应用的情况由运行时租约与设备侧保护覆盖，仍须验证实际效果。

## 视觉与交互基线

以下中性主题色来自参考项目；强调色、尺寸和状态映射是检测版的设计值，须通过实际显示和对比度检查。

| 项目 | 浅色 | 深色 / 说明 |
| --- | --- | --- |
| 内容背景 | `#FFFFFF` | `#141416` |
| 侧栏背景 | `#F4F4F6` | `#1C1C1F` |
| 主文字 | `#1D1D1F` | `#F5F5F7` |
| 普通主操作 | 蓝色强调 | 和停止/错误的红色区分；具体色值在主题测试中固定 |
| 结果颜色 | PASS 绿、WARN 琥珀、FAIL 红 | PENDING/SKIP 使用中性色；始终附带文字与图标 |
| 字号 | 正文 14、辅助 12–13、标题 22–26 | 关键错误与停止状态不使用低对比辅助色 |
| 间距与圆角 | 间距 4/8/12/16/24，面板圆角 8–12 | 表格密度和长文本优先于装饰 |
| 控件 | 常用按钮高 36–40，停止入口不小于 44 | 同时显示动作文字，不依赖单独图标 |
| 动效 | hover/淡入约 120–180ms | 遵循减少动画设置；停止、错误与状态确认立即呈现 |

支持跟随系统主题及手动切换。半透明侧栏和轻阴影可作为装饰，但正文、表单、错误提示和停止栏保持足够清晰；平台不支持透明效果时使用实色。普通文本目标对比度至少 4.5:1，大字及关键控件至少 3:1，验收时计算实际前景与背景组合。

键盘操作覆盖 Tab/Shift+Tab、表单提交、导航和日志搜索，焦点有可见轮廓。空格只遵循当前聚焦控件语义，不注册全局“开始/停止切换”；Enter 不绕过安全确认。停止使用独立命令，重复点击保持幂等，不承担“恢复运行”的第二种含义。

## 插件界面的限制与扩展

视图 schema 见[插件接口](plugin-api-v1.md#人工输入和视图描述)。插件选择通用组件、文案、资源及数据；壳拥有布局、无障碍标签、焦点、滚动和停止区域。图片只能引用包内资源或本轮受管 artifact，不直接加载任意网页。

v1 支持表单、说明、检查清单、测量值、表格、图片和简单时间曲线。点云、3D 机械臂、视频流和复杂标定交互如果成为真实需求，作为独立组件协议评估；不能以“插件化”名义在初版直接开放任意 JS UI 或 WebView 注入。

截图矩阵包含浅色/深色、`960×640`、`1180×780`、`1440×900` 逻辑尺寸及平台支持的 100%/125%/150%/200% 缩放；同时覆盖长中文、长路径、千行日志、几十个检测项和错误状态。组合可按风险选择，最小窗口与高缩放下的停止可见性必须全平台检查。

行为测试验证点击、焦点、取消和状态变化，不以固定标签顺序或像素完全相同代替交互验证。截图记录使用的平台、应用 SHA、插件摘要与窗口尺寸，区分源码窗口和打包产物。仅运行无头组件测试不能将 UI/UX 标记为已验收。
