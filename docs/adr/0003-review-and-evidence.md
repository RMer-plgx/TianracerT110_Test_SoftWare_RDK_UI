# ADR-0003. 持久保存人工复核与检测证据

## 状态

Proposed。目标与实现方式仍需确认，当前不具备完整的持久复核记录或证据追溯能力。

## 背景

报告需要保留检测事实，便于复核和排障。当前 HTML 在浏览器 `localStorage` 保存勾选状态，页面上的操作时间记录刷新后丢失，状态也不会随报告目录自动转移。电压项可能读取启动时 tap 文件，该读取未写入命令历史，因此报告中的电压值不一定能从 `raw.log` 找到。

## 决策

候选方向：

- WARN、SKIP、PENDING 的人工确认、撤销及理由作为独立记录保存，不改写原始状态和自动结论；FAIL 不由勾选覆盖。人工接受不等于自动通过。
- 记录检测批次、项目、原始状态、操作者、操作、理由和带时区的时间，与报告一同导出，并支持关闭后恢复；保存或导出失败时明确提示。
- 采集结果关联原始输出或其他证据；本地计算值说明来源、计算方式和采样时间。缺失、截断和采集失败必须可见，凭据不得写入报告或证据。
- 不同检测项无数据时使用 SKIP 还是 FAIL 需要逐项确定。当前电压项在底盘节点未运行或超时无有效电压时判 FAIL；调整前须评估交付判定与运动安全。

持久化格式、离线导入导出、操作者身份及防篡改范围尚未确定。

## 替代方案

- 仅保留浏览器本地状态：实现简单，但无法保证记录随报告迁移或保存完整操作历史。
- 人工复核直接覆盖自动结果：丢失原始检测事实，无法区分人工接受与实际通过。

## 影响

需要扩展报告数据和离线使用流程，并验证保存、重开、导出、失败提示及敏感信息处理。目标能力未实现前，不能宣称现有报告具备持久复核日志或完整证据链。
