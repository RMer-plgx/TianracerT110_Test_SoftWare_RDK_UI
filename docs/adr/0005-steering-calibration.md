# ADR-0005. 转向角只能间接测量，标定后才谈得上互校

## 状态

Proposed（2026-11-10）。首次标定已完成，结论可用；但只覆盖 14°~20° 区间，
更高角度、更高速度以及换车后的复现都未验证。

## 背景

第 18 项的「落地航向互校」原本只比较 IMU 与 odom 的航向差。这个指标有一个
盲区：**它比的是两个航向传感器，不比转向角。**

如果舵机卡在中位，车根本不转，IMU 和 odom 都是 0，差值也是 0 —— 反而判 PASS。
换句话说，原来的互校能发现「轮子转了车没转」（打滑），
**发现不了「转向执行没跟上指令」**。

要真正验证转向，就需要知道舵机实际转了多少。而这台车**读不到**：

```
协议下行帧只有四类：ODOM_RESPONSE / IMU_REPONSE / Voltage_RESPONSE / DEBUG_RESPONSE
没有任何一个携带转向角
```

改 MCU 固件加回传不在当前授权与能力范围内。

## 决策

在无法直接测量舵机角的前提下，采用**间接测量 + 一次性标定 + 常量修正**：

1. 用恒定转角跑稳态圆弧，从 IMU 实测角速度反推真实转角：
   `ω = θ_imu / T`，`R = v_real / ω`，`δ_real = atan(L / R)`
2. `v_real` 不能直接用指令速度 —— 打滑会让轮速高估。用
   `s = (|θ_odom| − |θ_imu|) / |θ_imu|`、`v_real = v_cmd / (1 + s)` 修正
3. 三路独立算法交叉验证（指令速度 / 打滑修正 / 弦长），偏差大则说明假设失效
4. 标定结果以 `steer_gain` / `steer_offset_deg` 写入 baseline，
   并用于把指令角换算成真实角

标定结果**不参与自动判定**，只作为报告里的测量项公布。等积累足够样本、
确认打滑修正稳定后，再考虑是否计入。

## 标定结果（2026-11-10）

轴距 0.255 m（卷尺实测），速度 0.12 m/s，单组 8~10 秒稳态圆弧，6 组有效数据。

```
δ_real = 0.910 · δ_cmd + 0.58°        残差 RMS 0.15°，最大 0.28°
```

| 指令 | 实际 | 比例 |
| --- | --- | --- |
| 14.32° | 13.74° | 0.959 |
| 17.19° | 15.94~16.28° | 0.927~0.947 |
| 20.05° | 18.79~19.00° | 0.937~0.948 |

左右对称性 0.2~0.3°，打滑率 26%~45%。

**0.35 rad（20.05°）指令，实际约 18.8°。** 这与「按名义 20.05° 算几何」
差 1.2°，对应半径从 0.699 m 变成 0.749 m —— 空间规划时按哪个算会差 7%。

三路交叉校验（0.35 左转）：若打滑均匀，
`R_C 应 ≈ R_B × (1+s) = 0.956`，实测 `0.879`，偏差 8%。
吻合度说明「打滑均匀」这个一阶假设成立，`δ_B` 是三者中最可信的。

## 替代方案

- **只比 IMU 与 odom**：能测打滑，测不出舵机偏差。已在用，但要认清边界。
- **人工拿量角器量**：只能静态抽查，无法反映负载下的实际转角。
- **改 MCU 固件加角度回传**：最彻底，但需要固件源码与烧写授权，当前不具备。
- **装外置角度传感器**：精度最高，需要加硬件、改线束。

## 影响

- `HARD_MAX_STEER = 0.5`（28.6°）是 2026-11-03 实现时随手定的保守上限，
  **不是厂家规格、不是实测**。本轮标定只验证到 0.35 rad，
  0.5 作为不可超越的硬顶保留，但没有任何数据支撑它对应真实物理限位。
  要确定真实限位，需要单独做「逐步加大转角直到车轮不再响应」的实验，
  风险较高，未做。
- 标定系数绑定**这台车、这个舵机、这个速度**。换车、换舵机、改悬挂后必须重测。
- 打滑率 26%~45% 说明 T110 在 0.12 m/s + 大转角时轮胎打滑严重。
  这既是 `spin` 闭合误差大的原因，也限制了间接测量的精度。
- `steer_gain` 用于把指令角换算成真实角，但**不改变下发的指令** ——
  检测工具不应该替底盘做闭环。若要让真实转角达到 20.05°，
  应按 `(20.05 − 0.58) / 0.910 = 21.4°` 下发，这属于底盘标定范畴，不在检测工具内做。

## 未验证

- 0.20 rad 以下（本次因场地不足未测）
- 0.35 rad 以上（未测，且无安全场地）
- 速度变化对标定的影响（本次固定 0.12 m/s）
- 负载/地面材质变化的影响
- 长时间使用后舵机中位漂移
